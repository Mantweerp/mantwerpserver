# SETUP REQUIREMENTS:

### fabric
yeahh lets just say you'll be needing this


### files
you'll need the files for the most recent version :D

mods files should be put into this directory/folder:
``C:\Users\<username>\AppData\Roaming\.minecraft\mods``

data packs should be put into this directory/folder:
``C:\Users\<username>\AppData\Roaming\.minecraft\resourcepacks``
